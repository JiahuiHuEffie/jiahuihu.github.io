# Personal Research Website

A minimalist personal research website built with HTML, CSS, and JavaScript.

## Features

- CV-based profile and research summary
- Selected research experience
- Publications and academic background
- Technical skills overview
- Responsive page layout

## Usage

1. Open `index.html` in your web browser to view the website.
2. Customize the content in `index.html`:
   - Replace any placeholder text with your actual project or publication details
   - Add a real portrait image in the hero section if desired
3. Modify `style.css` to adjust colors, fonts, or layout as needed.
4. Update `script.js` if you want to add more interactivity.

## Customization

- **Colors**: Change the color scheme by modifying the CSS variables or color values in `style.css`
- **Content**: Edit the HTML in `index.html` to add your personal information
- **Sections**: Add or remove experience, publications, or education cards as needed

## Deployment

This is a static website, so you can host it on:
- GitHub Pages
- Netlify
- Vercel
- Any static web host

## Troubleshooting

- For production use, consider adding interactive features if needed
- Test in multiple browsers for compatibility

## Dependencies

None - this is pure HTML, CSS, and JavaScript.
