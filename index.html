Current Projects

CAM-NET: Whole-Atmosphere Prediction

AI-driven foundation model for thermosphere and ionosphere extension with physics-informed learning.

Currently developing CAM-NET to support rapid atmospheric state forecasting by combining physics-informed models and machine learning techniques. This project focuses on improving operational readiness while maintaining strong physical consistency.

  • Designed model architecture for high-precision atmospheric prediction with a large speedup compared to conventional simulations.
  • Implemented PI-MVTI to reconstruct missing atmospheric LiDAR observations while enforcing mass conservation and buoyancy constraints.
  • Evaluated results with quantitative metrics and validation against independent datasets.

Expected result: a robust framework for practical atmospheric and ionospheric prediction, with an emphasis on physical consistency and operational readiness.

Preprint: https://arxiv.org/abs/2506.19340

Conditional Diffusion Model

Generative atmospheric perturbation prediction with conditional reverse diffusion.

Developing a conditional diffusion framework to predict temperature perturbation fields from WACCM-X dynamics. The model uses zonal wind and smoothed background temperature as conditioning information, then learns the reverse diffusion process needed to generate physically meaningful perturbation maps.

  • Prepared 3-hourly WACCM-X samples across 16 fixed geographic locations, separating background temperature from perturbation structure.
  • Constructed weekly input-target windows for conditional training using zonal wind, background temperature, and target perturbation fields.
  • Evaluated held-out predictions with correlation, MAE, RMSE, relative total variation, and power-spectrum comparisons.

Expected result: a generative model that maps atmospheric conditions to realistic temperature perturbation fields for fast analysis and forecasting support.

Ripple Recognition

Detect and characterize ionospheric ripple patterns in atmospheric fields.

Identify and characterize ionospheric ripple patterns using model-driven detection and signal analysis. This projection supports better understanding of atmospheric disturbance signatures in the upper atmosphere.

  • Detected ripple structures in electron density and ion drift fields with a physics-informed classifier.
  • Combined time-series features and spatial gradients to improve recognition accuracy.
  • Studied ripple evolution in response to geomagnetic storms and atmospheric forcing.

Preprint: https://arxiv.org/abs/2603.03669

Data Imputation

Physics-informed reconstruction of missing atmospheric and ionospheric measurements.

Reconstruct missing atmospheric and ionospheric observations using physics-informed imputation and machine learning. This projection focuses on closing data gaps from LiDAR, radar, and satellite measurements.

  • Applied PI-MVTI to infer missing data while preserving mass conservation and physical consistency.
  • Integrated observation uncertainty and representation error into the imputation model.
  • Prepared projections for higher-resolution atmospheric state recovery.

Publication: https://agupubs.onlinelibrary.wiley.com/doi/full/10.1029/2025JH000656
